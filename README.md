# Solid Diesel Trading L.L.C. Website

Static one-page corporate website (HTML, CSS and JavaScript in one file). No build step.

## Files
- `index.html`: the whole website
- `favicon.svg`, `assets/logo.svg`: fuel-drop logo
- `robots.txt`, `sitemap.xml`: replace `YOURDOMAIN.com` with the real domain

## Deploy
Import this repository in Vercel, Netlify or Cloudflare Pages. Framework preset: Other. Build command: none. Output directory: `/` (root).

## Edit
Contact details (phone, WhatsApp, email) are in `index.html`. Search for `971505532309` and `info@soliddiesel.com`.

## Note
The quote form builds a WhatsApp message. It does not send email. Connect a form service (Formspree, Resend, etc.) to receive email.
